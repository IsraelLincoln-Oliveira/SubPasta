# Automatizar Notas dos Aluno

Programa em Python que automatiza o cálculo das notas dos alunos de uma escola. Para cada aluno, ele lê as notas, calcula a média e informa a situação (Aprovado, Recuperação ou Reprovado).

Projeto desenvolvido como exercício do curso técnico em Desenvolvimento de Sistemas, com foco em funções com parâmetros (def).

## O que o programa faz:

1. Pede o nome do aluno e guarda na lista alunos.
2. Pede 4 notas (uma por bimestre) e guarda na lista notas.
3. Calcula a média das notas usando a função calcular_media.
4. Mostra a situação do aluno de acordo com a média.
5. Repete o ciclo para o próximo aluno.

## As notas podem ser digitadas com vírgula ou ponto (7,5 ou 7.5).

# Critério de aprovação

Média	                   /   Situação
7 ou mais	              /   Aprovado
5 ou mais e menos de 7	 /   Recuperação
Menos de 5	            /   Reprovado
